OH, SNAP! - Integrated (into the game view 'bar') Snapshot/Screenshot Tool for Unity.

> There's no particular setup necessary; just add the asset/script(s) to the project.
You should then see the 'Snap' and 'Preview' buttons, as well as the opacity slider.

Click ‘Snap’ to capture image of current game view..
-- Hold 'Preview' to see it as an overlay.

That's it!

Please see the live documentation for more information.
